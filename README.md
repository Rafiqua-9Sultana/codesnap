## ✦ THE IDEA

**Code deserves better than ordinary screenshots.**

</div>

CodeSnap is a browser-based developer tool designed to turn code snippets into visually stunning images.

Write code, experiment with themes, customize the preview, and export your creation as a high-quality PNG — all through one intuitive interface.

## 🚀 GETTING STARTED

### Prerequisites

- Node.js
- npm

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Rafiqua-9Sultana/codesnap.git
```

**2. Navigate to the project**

```bash
cd codesnap
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the application**

```bash
npm run dev
```

**5. Visit the application**

```text
http://localhost:5173/
```

## ✨ About CodeSnap

**CodeSnap** is a web-based developer tool that transforms ordinary code snippets into visually appealing images.

Whether you're sharing code on social media, creating tutorials, preparing documentation, or showcasing your programming work, CodeSnap makes it easy to generate beautiful code screenshots.

Its interactive editor and live preview allow you to customize the appearance of your code before exporting it as a high-quality PNG image.

## 🚀 Features

- **Live Code Editor** – Write and edit code with syntax highlighting.
- **Multiple Languages** – Support for Python, JavaScript, TypeScript, Java, HTML, and CSS.
- **Editor Themes** – Choose from Dracula, Monokai, Midnight, and Light themes.
- **Custom Backgrounds** – Select from beautiful gradient and solid-color backgrounds.
- **Font Customization** – Adjust code font size.
- **Preview Padding** – Control the spacing around your code.
- **Border Radius** – Customize the rounded corners of the code window.
- **Shadow Intensity** – Adjust the depth of the preview shadow.
- **Live Preview** – See your customization changes instantly.
- **Copy Code** – Copy your code directly to the clipboard.
- **Copy Image** – Copy the generated code image.
- **PNG Export** – Download high-quality code screenshots.
- **Responsive Design** – Enjoy a smooth experience across desktop and mobile devices.

## ⚙️ Getting Started

Follow these steps to run CodeSnap locally.

### Prerequisites

Make sure you have installed:

- Node.js
- npm

### 1. Clone the repository

```bash
git clone https://github.com/Rafiqua-9Sultana/codesnap.git
```

### 2. Navigate to the project directory

```bash
cd codesnap
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

Visit:

```text
http://localhost:5173/
```

## 🖥️ How to Use

1. Open CodeSnap in your browser.
2. Enter or edit your code in the editor.
3. Select your preferred programming language.
4. Choose an editor theme and background.
5. Customize font size, padding, border radius, and shadow.
6. Preview your design in real time.
7. Copy your code or image, or export the result as a PNG.

## 🌌 Overview

**CodeSnap** is a browser-based developer tool designed to transform code snippets into visually appealing images.

With a live code editor, multiple syntax themes, customizable backgrounds, and real-time preview controls, CodeSnap makes creating professional-looking code screenshots simple and enjoyable.

Whether you're preparing programming tutorials, sharing code snippets, creating documentation, or showcasing your development work, CodeSnap helps present your code beautifully.

## ⚡ Getting Started

Run CodeSnap locally in a few simple steps.

### Prerequisites

- Node.js
- npm

### 1. Clone the repository

```bash
git clone https://github.com/Rafiqua-9Sultana/codesnap.git
```

### 2. Navigate to the project

```bash
cd codesnap
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

```text
http://localhost:5173/
```

## ✨ Overview

**CodeSnap** is a modern, browser-based developer tool that transforms code snippets into beautiful, customizable images.

It provides a live preview and a collection of styling options that allow developers to personalize their code screenshots and export them as high-quality PNG images.

Whether you're sharing code on social media, documenting projects, or creating technical presentations, CodeSnap makes your code look better.

## 🚀 Features

- **Live Code Editor** — Write and edit code with syntax highlighting.
- **Multiple Languages** — Support for Python, JavaScript, TypeScript, Java, HTML, and CSS.
- **Editor Themes** — Choose from Dracula, Monokai, Midnight, and Light themes.
- **Custom Backgrounds** — Personalize your preview with gradient and solid-color backgrounds.
- **Font Size Control** — Adjust code font size to match your preference.
- **Preview Padding** — Control the spacing around your code window.
- **Border Radius** — Customize the rounded corners of your code window.
- **Shadow Intensity** — Adjust the depth and appearance of the preview shadow.
- **Live Preview** — See customization changes instantly.
- **Copy Code** — Copy your code directly to the clipboard.
- **Copy Image** — Copy the generated code image.
- **PNG Export** — Download high-quality code screenshots.
- **Responsive Design** — Enjoy a smooth experience across desktop, tablet, and mobile devices.

## ⚙️ Getting Started

Follow these steps to run CodeSnap locally.

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/Rafiqua-9Sultana/codesnap.git
```

### 2. Navigate to the Project

```bash
cd codesnap
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

Visit:

```text
http://localhost:5173
```

## 💡 How to Use

1. Open CodeSnap in your browser.
2. Select your preferred programming language.
3. Write or paste your code into the editor.
4. Choose an editor theme.
5. Select a background for your code preview.
6. Customize font size, padding, border radius, and shadow.
7. View your changes in the live preview.
8. Copy your code, copy the generated image, or export it as a PNG.
